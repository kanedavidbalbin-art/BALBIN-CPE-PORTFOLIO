# Kane David M. Balbin — Computer Engineering Portfolio

A responsive, single-page academic portfolio for a first-year BS Computer Engineering student at Mapúa University.

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `academic-portfolio`).
2. Upload the contents of this folder to the repository's root. Keep the `assets` folder and its files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. The site URL will be similar to `https://YOUR-USERNAME.github.io/academic-portfolio/`.

## Notes
- This is a static website. The email link opens the visitor's email application; it is not a backend contact form.
- Coursework PDFs and the Coursera certificate are included in `assets`.
- The Coursera certificate has a verification link in the website.
- Replace or add coursework files in `assets` and update the corresponding links in `index.html` as your portfolio grows.
